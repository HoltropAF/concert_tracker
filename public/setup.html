Fork the project on GitHub

GitHub hosts the code. You need your own copy (a "fork") so Vercel can deploy it under your account — and so any changes you make stay yours.

1. No GitHub account yet? Sign up here ↗ — then come back.

2. Click the button below. GitHub will show a confirmation page — just click Create fork.

Fork on GitHub ↗

Create your Supabase project

Supabase is your database. It stores all your concert data and handles logins. It's free and takes about 2 minutes to set up a new project.

1. No Supabase account? Sign up here ↗ — then come back.

2. In your Supabase dashboard, click New project. Give it any name — settracker works fine. Set any password. Click Create new project.

3. Wait about 2 minutes. You'll see a green status indicator when it's ready.

Open Supabase dashboard ↗

Deploy to Vercel

    
Vercel puts your app online for free. It takes the code from your GitHub fork and builds it into a live website at a *.vercel.app address.

    
1. Click the button below. Vercel will open its import page, already pointed at your fork.

    
On that page, Vercel will show a form with two fields — VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY. Paste the values from the previous step into those fields, then click Deploy.
