# SetTracker upgrades — 12 October 2026

- Complete JSON backup in Settings → Backup includes concerts, portable settings and uploaded photo bytes (200 MB maximum). External image URLs stay links; Spotify session tokens are excluded. Restore previews counts, retains unrelated concerts and uploads photos to new paths. Interrupted restores explicitly report partial completion. Photo files missing from the backup prevent restoration.
- Save feedback reports saving, saved and failed writes, with retry while the page remains open. Writes are serialized. Guest storage quota errors are surfaced instead of reporting success. Pending/failed writes trigger the browser's leave-page warning.
- Venue and friend pages expose missing map positions, lookup retry, coordinate entry and manual pin placement. Lookup calls are spaced out; map coordinates are validated. Single-venue friend maps now display too.
- Add concert starts compact, with frequent venue shortcuts and existing companion suggestions. Choosing a known venue fills its location, including country.
- Concert search supports artist plus optional city/date, paginated choices, source links, a review step and duplicate warnings. It uses the existing server-side setlist.fm key. Import fills a draft; saving remains explicit. Festival results describe individual performances, not full festival attendance.
- Concert details → General → Add to calendar downloads an `.ics` concert or ticket-sale event. Concerts are all-day; sale times are floating local times. This is a one-time export, not an ongoing subscription.
- `npm test` runs unit and existing import/export regressions. `npm run build` runs tests before building; GitHub Actions runs it on pushes and pull requests.
- A slow startup recovery overlay is removed when the app successfully mounts.
